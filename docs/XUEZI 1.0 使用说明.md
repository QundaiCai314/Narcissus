# XUEZI 1.1.0 使用说明

XUEZI 1.1.0 是一个可直接本地打开使用的 AI 学习与在线练习系统。

## 如何启动

直接双击打开：

`index.html`

建议使用 Chrome、Edge 或其他现代浏览器。

## 已包含功能

- 课程管理
- 资料上传
- TXT / Word / PDF 文本解析
- 文档重点难点总结
- 由 AI 解析章节、知识点、难点、易错点和可考方向
- 按学科门类设置出题方向
- RAG 检索资料片段辅助出题
- 生成候选题进度条
- AI 生成候选题
- 候选题精选入题库
- 题库题目管理
- 从题库创建试卷
- 试卷查看
- Word / PDF 导出
- 在线答题
- 逐题批改
- 客观题自动判分
- 主观题 AI 批改
- 错题知识点讲解
- 学习数据分析

## 在线答题怎么用

1. 进入课程工作台。
2. 打开 `在线答题`。
3. 选择练习题型：综合、只练客观题、只练主观题。
4. 选择题目来源：
   - 已有题库
   - 已创建试卷
   - AI 根据文档现出题
5. 设置题目数量并开始练习。
6. 每次只看一题，答完当前题后点击 `批改本题`。
7. 查看本题反馈和知识点讲解，再翻到下一题。
8. 多选题按完整选项集合批改；主观题会同时显示参考答案、评分依据和错误知识点详细讲解。答错后可选择“加入错题本”，也可以稍后移出。

## API 设置

点击右上角 `API 设置`，填写：

- API 地址
- API Key
- 模型名称

如果暂时不填写 API，也可以使用资料上传、题库、组卷、试卷导出和客观题批改等已有数据流程。知识点划分、生成候选题、AI 根据文档现出题和主观题 AI 批改需要配置 API。

## 文件说明

- `index.html`：主页面，直接打开即可使用
- `app.js`：核心交互逻辑
- `styles.css`：页面样式
- `vendor`：本地文档解析依赖
- `samples`：示例资料
- `docs`：说明文档

## 数据保存

课程、资料解析结果、题库、试卷、在线答题记录和 API 设置会保存在当前浏览器的 localStorage 中。

发送给别人时，直接发送整个 `XUEZI 1.1.0` 文件夹即可。

## 按章节或知识点出题

上传资料后，系统会在 API 已配置的情况下调用 AI 整理章节、知识点、难点、易错点和可考方向。未配置 API 时不会使用本地规则硬分知识点。

在右侧“出题参数”里：

- 组织方式选 `自动识别`：系统自动决定出题范围。
- 组织方式选 `按章节`：可以继续选择具体章节。
- 组织方式选 `按知识点`：可以继续选择具体知识点。
- 组织方式选 `按主题`：可以继续选择具体主题。

选择具体范围后，生成候选题会优先围绕该范围进行。

## 学习分析

完成在线答题并逐题批改后，进入 `学习分析` 可以查看：

- 已批改题目数量
- 平均得分
- 错题率
- 薄弱知识点
- 最近错题反馈

学习分析有两个按钮：

- `错题本`：只保存用户主动加入的错题，并可逐题移出。
- `数据分析`：展示正确率、平均得分、练习次数、图表说明，以及根据概念混淆、条件遗漏、步骤计算、迁移应用等错误类型生成的针对性建议。
