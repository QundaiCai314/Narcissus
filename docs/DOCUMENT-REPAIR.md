# 资料识别与检索修复

## 原因与处理

图片PDF可能带有少量乱码页眉。旧流程仅以字符数判定可用，导致整页正文未被读取，却产生了无意义的向量和导读。现在会检查控制字符、乱码及大幅图片和稀疏文字层，必要时逐页进行本地中文/英文识别。识别失败、低置信度或超时不会发布成可用资料。原页码和片段编号仍由后端保存，识别结果会显示图片页数与核对原文提示。

概览问题改为在当前用户、笔记本和所选资料范围内跨页取材，避免通用问题被语义相似度阈值全部过滤。资料导读、总结与学习内容也先覆盖各页，再补充主题检索；上下文仍有上限。学习任务使用较紧凑的证据片段，导图默认聚焦最多18个重点节点（接口硬上限仍为40）。细节问题继续使用原有检索阈值，无关问题不得从外部知识补充。生成和复核提示明确区分判断题中被标记为错误的命题，跳过明显乱码与无法识别的公式。

导图总览节点现在是服务端的资料导航，不包含模型生成的事实概述；知识分支仍经过引文和语义复核。较长但完全匹配证据的引文会分成多个短引文，完整保留内容；虚构或改写的引文仍拒绝。模型仅遗漏完整JSON对象末尾闭合符时允许有限语法修复，缺失正文、字段或错误节点不补造。问答预算默认从2048调整为8192，避免当前推理模型耗尽预算后只输出半截回答；已有`.env`也应设置`CHAT_MAX_TOKENS=8192`。

## 更新服务

在项目目录执行 `docker compose up -d --build`。不增加表或修改历史数据结构，继续使用迁移005，已有数据卷和文件保留。后端镜像新增 Poppler 与 Tesseract 简体中文语言包；首次构建需要下载系统软件包。普通宿主机运行需自行安装 `pdftoppm`、`tesseract` 和 `chi_sim` / `eng` 语言数据。

`.env` 可配置 `OCR_ENABLED=true`、`OCR_MAX_PAGES=30`、`OCR_PAGE_TIMEOUT_SECONDS=30`、`OCR_TOTAL_TIMEOUT_SECONDS=160`。已有 `.env` 不必添加也会使用这些默认值。PDF整体上限仍是200MB、100页。识别使用后台CPU，文件不会为识别发送到额外云服务；后续向量和生成沿用已配置模型。

POST `/api/documents/{id}/reprocess` 请求体为 `{"version":当前generation}`，所有权由服务端校验。重复请求使用同一版本会返回409，避免重复处理。重处理增加版本，取消仍在执行的相关生成，旧任务不得写回；已有笔记和学习记录保留，旧成果显示资料变更。资料可用后自动重建导读，其他成果通过“生成新版”基于新版本生成。

## 验证方式

`tests/test_document_repair.py` 覆盖乱码检测、稀疏图片层识别、识别失败、跨页覆盖、概览路由、访问隔离和重复重处理版本校验。可在既有独立测试环境执行：`docker compose -p narcissus-test -f compose.yaml -f compose.test.yaml run --rm --build tester pytest -q tests/test_document_repair.py`。

## 实测记录（2026-10-08）

- 用户指定的17页中文金融学扫描PDF（约36.2MiB）：原索引只有714个乱码字符；本地识别提取26,118字，生成45个有页码的片段，单次离线识别耗时87.5秒。当前资料已在真实Worker中重新处理并建立向量，版本升级为2。
- 真实阶跃星辰模型：两个原始问题均产生完整回答和有效来源编号；关于火星基地的无关问题返回依据不足。新版导读已替换旧乱码导读；最新导图保留6个节点、闪卡10张、测验5道，均已持久化。导图候选18个节点中12个未通过引文或语义复核，页面明确显示剔除说明，未为凑数发布。
- 手工对照原PDF第1、7页，抽查货币职能、货币政策工具相关内容及引用页码；数字、公式仍保留识别误差提示。
- 最终导图“公开市场业务”节点携带服务端校验的成果ID和节点ID继续提问，实际得到546字完整回答及5个有效原文引用，状态为complete。
- 独立全栈回归首次72项通过，新增权限测试因测试程序的向量服务地址与Worker不一致失败；修正测试配置后该测试通过。后续资料修复与学习结构/引文/超时测试23项通过；新增流式截断用量回归后，本次专用测试文件10项全部通过（上述计数存在重叠）。前端生产构建与TypeScript检查通过。
- 浏览器在已有测试笔记本验证导图缩放与适应屏幕、折叠/展开，闪卡翻面、掌握/复习标记及刷新后进度恢复。当前金融学笔记本通过真实后端任务和问答流程验证；没有把另一账号测试页面冒充该用户页面。

图片中文字识别不保证逐字正确，特别是数学公式、细小数字、低分辨率和复杂栏布局。学习成果采用有限片段取材，不能保证涵盖全文所有知识点；被拒绝的内容不会为凑数重新包装为事实。
