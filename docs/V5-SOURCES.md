# 多来源导入及来源版本

左侧“添加资料”支持批量 PDF、DOCX、TXT、Markdown、PNG/JPG，以及粘贴文字和普通网页。默认每批 10 份、每笔记本 10 份、单文件 200MB、PDF 100 页；DOCX 解压 60MB，正文 50 万字符，索引 800 片段。限制均由后端执行，客户端显示当前配置。

DOCX 按正文顺序提取标题、段落、列表及表格行，不编造分页。旧 DOC 不支持；复杂公式/批注/文本框给提示，嵌套表格拒绝。TXT/Markdown 支持严格 UTF-8、UTF-8 BOM、GB18030，UTF-16 需 BOM；不可靠编码拒绝入库。Markdown 原始 HTML 不执行。

本地 OCR 使用 Poppler + Tesseract（中文简体和英文）。Docker 镜像已安装依赖，无需云 OCR 密钥。文字层可用的 PDF 页面直接解析，缺少文字的页面才识别；支持混合 PDF 和独立图片。默认单份最多 OCR 30 页、单页 30 秒、总计 160 秒，每用户每日 200 页，可通过 OCR_* 配置。显示服务真实提供的置信信息，不保证数字/公式/排版识别准确。部分页面失败会停在待确认，用户可重试或确认使用部分正文；不会显示为完整成功。

原件仍在私有对象存储，正文与定位在 SourceVersion 中。Chunk 包含版本及稳定段落标识：PDF 为页码，图片为图片序号，Word 为标题/段落/表格行，网页为章节/段落，文本为行号。新版本成功索引后才切换活动版本；历史版本片段继续供旧引用核对。文本及 OCR 修正建立新版本，不修改旧引文；原图关联保留。

网页先获取和预览，用户确认才索引；保存抓取时间、原始响应、提取正文及用户调整标识。手动重新获取创建新版本，失败时仍可使用旧版。对内网地址、重定向、DNS 重绑定、响应大小、超时、内容类型进行服务端限制。

相同笔记本内按文件哈希/内容哈希检测重复；跨用户不暴露重复信息。默认不重复索引，用户可明确保留独立副本。源文件删除通过持久化清理任务覆盖所有版本对象，Worker 以任务认领标识和来源版本校验，取消/删除之后不能写回。重试不重复写入同版索引。

升级需要数据库迁移 006 和 007（007 包含待确认状态长度兼容修复）。备份脚本覆盖历史版本原件和音频对象；数据库备份同时包含网页候选及正文快照。不要仅备份最新 PDF。
