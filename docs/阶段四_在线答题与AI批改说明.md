# 阶段四：在线答题与 AI 批改说明

阶段四新增独立的“在线答题”模块，不改变“候选题 → 题库 → 组卷”的已有流程。

## 核心流程

1. 用户进入课程工作台。
2. 打开“在线答题”页签。
3. 选择练习题型：
   - 主观题 + 客观题
   - 只练客观题
   - 只练主观题
4. 选择题目来源：
   - 已有题库
   - 已创建试卷
   - AI 根据文档现出题
5. 设置题目数量并开始练习。
6. 用户一次只看到一题，可以上一题、下一题翻页。
7. 用户答完当前题后点击“批改本题”。
8. 系统立即批改当前题。
9. 做错或不完整时，系统补充知识点讲解和下一步建议。

## 批改规则

- 客观题使用本地规则逐题判分。
- 主观题优先调用已配置的 API 逐题批改。
- 没有 API 或 API 调用失败时，会使用本地参考规则生成基础反馈。
- AI 根据文档现出题需要配置 API；未配置 API 时会提示先配置。
- AI 批改提示词中加入了教育心理学和真实教师风格要求：
  - 形成性评价
  - 掌握学习
  - 检索练习
  - 错因诊断
  - 最近发展区
  - 客观、公正、有温度的反馈

## 设计原则

- 在线答题是新的学习模块，不等同于组卷。
- 练习时只呈现一道题，降低认知负荷。
- 每题独立批改，反馈更及时。
- 翻页保留用户答案。
- 批改后不只告诉对错，还要说明错在哪里、该复习什么知识点。
- 主观题反馈避免羞辱式评价，采用真实教师的具体建议。
