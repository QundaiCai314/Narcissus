## 有针对性的自动化验证

- 两个用户对成果、进度、测验尝试、生成/取消/重试、作答等直接调用均不能越权；跨笔记本节点上下文被拒绝。基础测试包含私有文件访问隔离。
- 文档上传、异步解析、非法/扫描/加密/超限拒绝、处理失败与重试、文件删除清理由基础测试覆盖。
- 等待任务与生成结果隔离、幂等创建、同一任务重复投递、有限3次重试、输出格式错误、依据不足、取消、租约过期恢复及总超时。
- 导图非法/重复ID、环、孤儿、四层结构、未知来源、伪造逐字引文、重复选项、布尔答案索引拒绝。引用修复不改写事实，不接受未知来源；修复后仍无依据的节点及后代移除。
- 独立作答复核识别多项成立、复核答案与生成答案不一致；不会因 approved_ids 中有该题就放行。
- 闪卡顺序、随机顺序、游标、掌握/需复习、筛选、删除、旧revision冲突均持久化。
- 测验未提交和仅保存选择时，题目不含正确答案、解释、知识点、引文或原文；提交仅揭示本题。重复并发提交幂等，改写已提交答案409，评分正确，错题轮次与新完整轮次保留历史。
- 来源版本变动标记、删除保留引用快照、删除期间任务取消、防迟到回写、笔记本删除级联清理。

来源更新测试使用受控的数据库版本变更；当前没有替换PDF的产品界面。超时和坏结构测试采用故障注入，未故意长时间占用真实供应商。

## 已知限制

- 生成质量仍取决于模型。严格复核可能大幅减少题量、拒绝可用条目，或有漏检；应核对重要内容。本次实测已把发现的问题如实记录并修复，未把引用存在当成事实成立。
- 默认10题通常需要1次生成、1次独立作答和逐题证据审核，模型耗时与费用高于普通问答；最多3路并发，整体180秒，失败有限重试。
- 长资料使用有界检索和分散片段，不能保证穷尽全文、全部矛盾和复杂跨段推理。未进行大规模质量基准、并发压测或公网生产部署。
- 学习成果不支持导出、公开分享、复杂间隔重复或主观题，本轮范围内笔记/总结的Markdown与DOCX导出保持原功能。
- DOCX已验证结构和引用，沿用第二版限制：未安装办公软件进行分页渲染比对。PDF复杂多栏/表格仍受文本提取顺序限制，扫描件OCR未实现。
