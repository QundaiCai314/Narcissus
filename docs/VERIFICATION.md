## 未完成实测与边界

1. 没有提供真实 Chat / Embedding 密钥，因此尚未实测供应商鉴权、真实中文语义检索质量、实际生成质量、文档提示注入抵抗能力及供应商计费/用量兼容性。实现已接真实兼容接口，填写密钥后需按业务文档验收；不会用固定答案替代真实调用。
2. 未部署到公网、申请域名/证书或创建付费资源。HTTPS、生产凭证、数据政策和备份调度需按部署文档配置。
3. 没有 OCR、精确文字高亮及其他明确排除的扩展功能；复杂多栏、表格的提取顺序依赖 pypdf。
4. 引用编号、文件、页码和片段由服务端约束；不能自动证明每一句话都被引文语义支持。引用门控按段落输出，可能比逐 token 流式显示多一点等待。
5. 采用精确向量检索，未做大规模性能/负载测试。邮箱验证、密码找回、管理后台与商业化运营功能不在本版。
6. 基本限流使用账户和后端连接来源；同域代理下来源限流会聚合为代理地址。第一版适合小规模试用，扩大访问量前应在可信入口补充真实客户端 IP 限流，并重新校准阈值。
