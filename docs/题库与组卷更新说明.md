# 题库与组卷更新说明

本次更新把“题库”和“试卷”拆成两个独立板块。

## 新增能力

- 题库页负责管理题目和创建试卷。
- 题库支持“用所选题目创建试卷”“全选题目”“取消选择”“删除所选”“删除此题”和“一键清空题库”。
- 试卷页独立展示多套试卷。
- 用户点击试卷卡片中的“查看”后，才展开试卷内容。
- 点进试卷后，可以看到两部分：
  - 试卷：只包含题目和选项，不带答案。
  - 答案与解析：单独列出答案、解析和知识点。
- 每套试卷会保存题目快照，后续整理或清空题库不会影响已组好的卷子。
- 支持导出 Word。
- 支持导出 PDF：点击后打开打印窗口，选择“另存为 PDF”即可。
- 导出文件采用常见试卷结构：考生信息栏、答题说明、试题区、独立答案解析页。
- 选择题和填空题保留较短作答区，简答题和论述题保留更大的作答空间。
- 答案与解析强制另起一页，不和试卷题目出现在同一页。
- 文件管理支持删除资料。删除资料会同步删除该资料解析出的文本片段，但不会自动删除已精选进题库或试卷的题目。

## 使用流程

1. 在“候选题”中把满意题目加入题库。
2. 进入“题库”，按需要删除单题、删除所选或清空题库。
3. 在“题库”中勾选需要进入同一套试卷的题目。
4. 点击“用所选题目创建试卷”。
6. 输入试卷名称。
7. 进入“试卷”，在“已有试卷”中点击“查看”。
8. 检查卷面和答案解析。
9. 点击“导出 Word”或“导出 PDF”。
