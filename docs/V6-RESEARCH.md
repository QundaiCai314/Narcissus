# 第六版：联网研究

入口：笔记本右侧工作室 → **联网研究**。输入问题后搜索，逐个“获取正文预览”，核对或清理正文，勾选并确认导入。只有成功入库且明确选择的资料会用于报告。已有笔记本资料需要另外勾选。

## 服务配置

实现阶跃星辰的独立 `POST /v1/search`，不是聊天的内置搜索工具。选择原因：项目已使用该供应商；官方提供独立检索接口，可复用账户并分开设置凭证。接口文档：https://platform.stepfun.com/docs/zh/api-reference/search/search 。请求使用 `query` 和 `n`；供应商返回的 `time` 是索引时间，不能当作发布时间；其 `content` 字段也不作为本产品获取的正文。

在服务端 `.env` 中设置：

```dotenv
SEARCH_API_KEY=填写可调用搜索接口的密钥
SEARCH_BASE_URL=https://api.stepfun.com/v1
SEARCH_REUSE_STEPFUN_KEY=false
SEARCH_TIMEOUT_SECONDS=40
RESEARCH_MAX_RESULTS=10
RESEARCH_MAX_FETCHES=8
RESEARCH_DAILY_SEARCHES=20
RESEARCH_USER_CONCURRENCY=2
RESEARCH_MAX_ATTEMPTS=3
RESEARCH_MAX_TOKENS=16384
```

若聊天已经使用官方 StepFun 接口，可不重复填写密钥，改为 `SEARCH_REUSE_STEPFUN_KEY=true`。仅当聊天和搜索地址均为官方同一地址时才允许复用，避免密钥被发送到其他服务。前端不接收密钥。未配置时明确显示不可搜索，不使用演示结果。

本版默认原问题一次搜索，英文偏好添加可见的 English 检索词；暂不生成扩展搜索词。供应商当前没有语言或时间过滤参数，界面明确说明语言只是偏好，时间过滤不可用。结果最多 20 条（默认 10）。每研究默认最多 8 次网页获取，重试也计入；每用户每日最多 60 次获取。每研究最多 10 个报告版本，每用户每天最多创建 20 个报告。每次模型生成最多一次结构修复和一次语义复核；超时或失败不会后台无限重试。

部署者应保留 `WEB_DNS_MODE=system`。若网络代理把所有 DNS 结果改为 198.18/15 等非公网地址，导入会安全拒绝。可显式设置 `WEB_DNS_MODE=cloudflare`，使用固定 1.1.1.1 HTTPS 加密解析，再校验所有地址并固定目标连接；仍不会允许内网目标。该模式需要部署环境能访问 Cloudflare DoH，不是绕过 SSRF 检查的开关。

## 升级与启动

先按 README 备份，停写入服务，再升级：

```sh
docker compose stop web api worker beat
docker compose build
docker compose run --rm migrate
docker compose up -d
docker compose logs -f api worker beat
```

`alembic upgrade head` 会顺序执行 `006` 与 `007`，保留原数据。`006` 添加来源类型、活动版本及历史快照，保留已有片段 ID 和 PDF 页码；`007` 添加研究任务/候选来源，并将旧处理任务状态字段扩展至 24 字符以支持“待确认”。不要删除卷，不要用新建空数据库替代升级。

研究搜索和获取通过数据库 outbox + Celery Worker 执行，现有 beat 每 10 秒调度及恢复。浏览器刷新不会丢任务。任务超时后标记失败并要求手动重试，不会对结果不明的远程搜索自动重复计费；已取得的有效预览直接复用。搜索额度在 Redis AOF 中计数，删任务不能重置日额度。

## 数据、引用与安全

- `research_tasks`：所属笔记本、幂等键、问题、参数、实际检索词、调用记录、状态及报告版本关联。
- `research_candidates`：唯一规范链接、供应商摘要、独立获取状态、有限大小的原始响应及安全正文快照、获取时间、选择状态、导入资料关联。预览保存在私有数据库，不自动占用笔记本资料位。
- 确认后将同一原始响应写入私有对象存储，通过 `SourceVersion → Chunk` 接入统一索引。不会在确认时重新抓取网页。清理正文会标注用户调整并保留原获取快照。
- 报告复用 `Writing / GenerationJob / WritingCitation`。每次重新生成创建新 Writing，并保存固定的原始资料版本集合；编辑有乐观并发保护及“内容已修改”提示。可在报告窗口导出 Markdown/DOCX。
- 生成前后都检查来源版本。运行期间资料更新或删除会取消生成并要求重新选择，不会偷偷切换正文。旧成果保留原引用快照和版本；原始资料被删后不能跳转。
- 报告证据由选定原始资料的有界检索提供，补入命中片段的有限相邻段落，保留定义与例外列表的上下文；最多64个片段并受总字数限制。后端验证编号、逐字引文，并进行独立模型复核；未获支持的段落剔除，主要结论全部被拒绝则任务失败。事实、作者观点、推断分别标注。复核不能取代人工判断。
- 搜索摘要、供应商返回的整页文本及报告本身都不是新证据。报告追问使用原始资料，后续学习和音频继续使用这些已入库资料。若资料版本已更新，继续提问前会明确提示使用当前版本；旧报告引用仍使用旧快照。缺失或不可用的来源不能静默忽略。
- 初始 URL 和每次重定向均经过现有 SSRF 校验；目标 IP 固定、TLS 验证原主机，不携带用户 Cookie 或认证。HTML 只提取文本，不能执行脚本。
- 删除研究记录会取消其未完成阶段、删除候选预览，**保留已导入资料和已保存报告**。删除笔记本则清理全部关联数据；被取消或已删除任务不能重新发布。

API 文档位于 `/api/docs`。主要端点：`/notebooks/{id}/research`、`/research/{id}`、`/sources/{candidate}/fetch`、`/sources/{candidate}/import`、`/selection`、`/reports`、`/cancel`、`/retry`。任务列表使用 offset/limit（默认 30，最大 100），所有接口由服务端校验所属用户。

## 支持边界

支持无需登录、直接返回 HTML/纯文本的普通公开网页；不绕过登录、验证码、付费墙及脚本渲染限制。失败来源可改为“粘贴正文”，该方式保留用户输入身份。重复链接按规范 URL 合并；相同正文由入库内容哈希提示重复，不能据相似转载数量推断可信度。语义上的转载识别并非完整新闻溯源系统。

这是有上限的一轮研究，不实现自动反复搜索、Deep Research、定时监控或联网工具自主执行。生成报告是对已获取片段的归纳，不保证覆盖网站全部内容，日期未知不补造。
