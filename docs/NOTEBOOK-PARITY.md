## 使用入口

- 思维导图工具栏：下载只读HTML、分享导图。文件仅包含标题与层级，不含引用片段、正文、聊天或登录信息。浏览器不支持文件分享时改为下载。分享出去的文件副本无法远程撤销。
- 添加资料：上传CSV/PPTX/SRT/VTT，或用既有PDF/Word/文字/图片入口。字幕导入仅代表字幕文字，不代表读取了视频或听过原声。
- 来源预览：修正识别文字 → 公式结构选板 / 按原件修正表格 → 预览 → 保存为新版本。疑似“M。mB”“8B”只提示，不自动替换。
- 工作室：数据表、视频概览都在现有弹窗中打开。视频需要同一组来源版本、当前版本PDF导出和已完成音频；最多30页、5分钟，在Chrome/Edge按实际时长录制，可取消。
- 研究记录：已完成任务 → 检查报告缺口与轮数预算 → 选缺口 → 确认补检索。最多3轮包含初始搜索。轮数不等于调用次数；搜索重试、正文获取、报告生成仍按现有服务计费。
- 音频详情：保存到离线音频库 → 设置至少8字符口令 → 加密保存 → 打开离线库。应先联网打开离线库一次，待应用壳就绪后再断网。忘记口令只能移除副本后重新保存。单文件80MB、每账号浏览器软上限250MB；清理浏览器存储会丢失本地副本。

## 解析和导出约束

CSV最多5000行、100列，保留前导零、引号内换行及公式字面文字，不计算单元格。PPTX按演示文稿关系中的实际幻灯片顺序读取，最多100页；不提取图片、公式对象、图表、备注、动画，也不能保证复杂组合图形文字完整。导入后仍应核对原件。

来源数据表展示原始表格单元格，首行按表头显示。XLSX全部写成字面字符串；CSV对可能被表格软件执行的公式前缀增加单引号，所以导出的CSV与原始CSV并非逐字节相同。需要原始内容时下载原件。

离线音频使用随机盐/IV、PBKDF2-SHA256（150000次）及AES-GCM256；标题、媒体类型与音频一并加密。口令不持久保存。浏览器缓存只保存公开应用壳与静态资源，跳过API和私有笔记本HTML。离线解锁凭口令完成，并不构成服务器身份验证；已下载副本无法由服务器撤销。PWA需要安全上下文，localhost可用于本机测试；其他设备访问需要HTTPS。

## 手记协作启用步骤（须先获生产迁移授权）

默认配置 `COLLABORATION_ENABLED=false`，现有私有API继续只允许所有者。只读能力检查无需成员表；所有共享读写在开关关闭时先返回503。成员必须是已注册账号；当前没有自动发邮件或匿名公开链接。

010迁移仅新建`notebook_members`，含笔记本/用户复合主键、阅读者/编辑者约束及外键，不改原有业务行。先只读确认生产`alembic_version`恰为009；授权后才执行：

将`$deploymentProject`设为现有部署的Compose项目名，沿用现有卷和容器命名，不新建另一套部署。

```powershell
docker compose -p $deploymentProject exec -T api alembic upgrade 010
# 在被Git忽略的本地.env中设置 COLLABORATION_ENABLED=true
docker compose -p $deploymentProject up -d --no-deps api
```

不使用`upgrade head`来跳过版本审查。撤销启用时将开关改回false并仅重建api；不删除成员表或现有数据。启用后仍需验证两个独立账号：阅读者不能写；编辑者可修改手记但不能访问私有资料；版本冲突返回409；所有者撤销后新请求失权。修改与撤销通过笔记本行锁串行化。已成功完成的请求或收件人保存的副本不会被追溯撤回。
