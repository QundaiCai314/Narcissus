# 大学课程与考研复习：出题与练习

本次完善面向大学课程及考研复习的完整流程：选择原始资料 → 确认课程、章节、题型、难度和题数 → 生成并复核 → 逐题练习或整卷自测 → 核对解析与评分要点 → 错题重练与导出。

## 出题与作答界面

出题分为「选择资料」「设置试卷」「确认方案」三步；返回上一步保留设置。确认页列出资料、复习范围、各题型数量与分值及总分，避免生成前遗漏条件。所选题型多于题数时不能继续。

工作室的九个创建入口使用居中纸感弹窗；背景保留当前笔记本，点击关闭、遮罩或 Escape 返回对话。已生成的测验使用全屏专注答题布局。进入已生成的测验后，不显示课程标题、创建入口、学习版本列表、试卷来源详情和生成提示条；练习记录与设置默认折叠。左上角 Narcissus Logo 返回主页，右侧箭头入口返回对话；两者均保留未保存提醒。创建新练习时仍显示完整设置流程。桌面答题卡位于题目旁，手机可按需展开。题目切换后焦点回到题目区，上一题、下一题和保存状态保持易于查看。刷新通过页面地址恢复当前试卷及已保存的练习；保存失败保留草稿，切题先重试保存，离开时提示尚未保存的内容。

作答过程中显示完成进度；交卷后存在待自评题目时提示完成自评，全部评定后才显示原始总分和百分制成绩，并标注包含自评。

非选择题使用论坛式图标工具栏，支持加粗、斜体、公式、表情、图片和编辑／预览切换。公式面板按常用符号、希腊字母、分式、上下标、根式、积分、求和与乘积、极限与函数、括号与分段、矩阵、箭头与重音分类，支持搜索及最近使用。选结构后直接填写占位框，Tab 切换，可嵌套结构，也可切换 LaTeX 输入；行内或独立公式插入后随文字自动保存。双击预览公式或展开「修改已插入的公式」可再次编辑。未填占位框不能插入；尚未插入的公式与失败上传会阻止切题、提交，离开时沿用草稿保护。MathLive 按需加载，字体及许可证随前端部署，不调用外部 CDN。

通过选择文件、拖入或粘贴截图上传 JPG、PNG 或 WebP 手写作答（每次一张），每张最多 8 MB、2500 万像素，每题最多 4 张。服务器校验内容、按拍摄方向旋转并缩小至最长边 3000 像素，转换为 JPEG 并去除元数据。图片保存在私有对象存储，通过当前账户鉴权查看；上传成功即保存，文字修改不会覆盖图片。支持查看大图、删除和上传失败重试。仅图片的答案也计为已作答，提交后按评分要点自评；本功能不自动识别或批改手写内容。复盘导出包含需登录查看的图片链接。

## 题型和组卷

支持单项选择、多项选择、判断、填空、名词解释、简答、计算与证明、论述、材料分析九类。课程基础、理工计算、人文社科等预设用于快速选择题型，不冒充官方试卷结构。参考了中国教育考试网教育综合大纲和高校自命题大纲呈现的多种题型；具体考试始终以报考院校和科目大纲为准。

- [中国教育考试网：教育综合考试大纲](https://www.neea.edu.cn/res/Home/2308/1dc2cadc9383c5d8bd16dfb3166e63cf.pdf)
- [中国科学技术大学：2026 自命题科目考试大纲](https://yz.ustc.edu.cn/static/upload/article/ueditor/baf0843cb55b4d2ba21f689e4b7bbb7e.pdf)
- [桂林电子科技大学：2026 自命题科目考试大纲](https://www.guet.edu.cn/_upload/article/files/51/ec/0012d7f74283849abda1bc1359a3/a192128d-bcef-499b-b4df-ffd5eaedb2c4.pdf)

题数按所选题型顺序平均分配，余题分给前面的题型。界面在生成前列出方案和总分；证据不足允许少出，不能用其他题型替代。每题分值属于本应用练习规则，可在确认方案时查看，不声称是官方考试分值。

## 质量与反馈

题干必须写清条件、单位、范围和要求；选项统一显示 A—D。服务端验证题型、正确选项、数量、重复题、原文引文与评分分值。复核模型先独立作答，不看到参考答案和评分要点；非选择题再比较独立解答、参考答案、推导和评分要点。

选择题自动判分，多选须全部选对，少选、多选、错选均不得分。非选择题先独立作答、提交后查看参考答案，再按各评分要点自评，可给部分分。自评分明确标记，不冒充 AI 或教师批改；不使用简单字符串匹配判定公式和等价表述。自评未完成时不显示最终总成绩。

逐题模式在提交本题后显示答案；整卷模式只有交卷后才显示。交卷确认说明未作答题数及计零分规则。原始分与百分制成绩同时显示。答题卡区分当前、未作答、已作答、待自评和待巩固；刷新恢复已保存的作答，保存冲突要求重新加载。重练只复制本轮未满分题，保留历史成绩。复盘可导出 Markdown。

## 兼容与运行边界

沿用现有 JSON 字段保存题型、评分要点与进度，不增加数据库迁移。历史单选题与已有作答继续按原有等权规则读取。新前端检查后端能力，旧后端不会误接收新题型。正式启用需要同步升级 web、api 和 worker。

HTTP 402 提示模型额度或账单不可用；401、403、404 分别提示凭证、授权、地址或模型问题。出题遇到这些不可自动恢复的错误会停止后台重试，额度恢复后可由用户重试。
